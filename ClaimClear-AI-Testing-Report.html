3. Security measures implemented

MeasureDetail
No secrets in repoNo API keys, tokens, or .env credentials in source
XSS-safe UI renderingUser/bot text via React children (escaped); no dangerouslySetInnerHTML in components
Input length limitsChat 2000; escalate fields 500 / note 2000; status claim/name max lengths
Validation + safe failuresEmpty/wrong lookups and empty send show alerts; handlers wrapped in try/catch
Error boundaryReact crashes show recovery UI instead of blank crash
Dependency auditnpm audit: 0 vulnerabilities (React 19, Vite 6)
Demo data isolationSimulated claims only; no live backend / no real PII APIs

4. Accessibility features added

  • Skip link — “Skip to main content” → #main-panel
  • Labels — Chat “Your question”; status claim/last name; escalate name/claim/note
  • Checkboxes — Document rows labeled; Space toggles
  • Current page — Sidebar aria-current="page" on active tab
  • Focus — :focus-visible teal outline (2px #146B5D)
  • Errors — role="alert", aria-invalid, aria-describedby on chat/status/escalate fields
  • Keyboard — Enter send, Space checkboxes, focusable native controls throughout
